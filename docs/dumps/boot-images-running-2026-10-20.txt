# One unit per board, read-only over ssh as root. The boot partition is the one whose uevent says
# PARTNAME=boot (mmcblk0p9 on all three units, 16777216 bytes). Each pin's size was hashed off the partition;
# the partition is larger than any image, so only the first <size> bytes can match.
#
# Commands, per unit:
#   cat /proc/version
#   for n in 13156352 13172736 13553664; do head -c $n /dev/mmcblk0p9 | sha256sum; done
#   head -c 1024 /dev/mmcblk0p9            (Android boot header: kernel size, ramdisk size, page size)
#   head -c $((2048+kernel_size)) /dev/mmcblk0p9 | tail -c kernel_size | zcat | grep -a 'Linux version'
#
# `uname -r` is 4.9.337-g8d928c5176cc on every image below, so it can't tell them apart. The build date in
# /proc/version can.
